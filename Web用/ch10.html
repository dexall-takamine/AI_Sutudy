AIシステムの設計

この章のゴール
個別技術ではなく AIシステム全体がどう設計されるのか を理解する。RAG・AIエージェント・MCP・マルチエージェント の各アーキテクチャと、AI導入の進め方を説明できるようになる。

この章を学ぶ理由

LLM・Transformer・RAG・Vector Database・MCP・AIエージェントなど、これまで学んだ技術は単独ではほとんど使われない。実務では複数を組み合わせて1つのシステムを作る。その設計知識は、AIエンジニアだけでなくDX担当者・ITコンサル・PMにも求められる。

10-1AIシステムの全体像

一言でいうとAIシステムとは、LLM・データ・ツール・外部システムを組み合わせて業務を支援・自動化するシステム全体のこと。LLMはその「頭脳」だが、頭脳だけでは仕事はできない。
✕ 誤解ChatGPT ＝ AIシステム
○ 正しくはChatGPTなどのLLMはAIシステムの一部。多くの技術を組み合わせて初めて実務で使えるシステムになる

企業向けAIシステムは、一般的に次のような階層で構成される。

UI（チャット画面・Teams・Slack・Webアプリ）
AIエージェントGoal・Planner・Memory・Reflection で仕事全体を管理
LLM / RAG / Browser Agent / Function Calling生成・検索・Web調査・ツール呼び出し
Vector Database ／ MCP意味検索の保存先 ／ AIとツールの共通接続規格
社内システム・API・DB（Salesforce / SAP / GitHub / Jira / Google Workspace）

図 10-2　1つの依頼に対し複数の技術が連携して動く
システムの品質はLLMだけでは決まらない

初心者は高性能なLLMを選べばよいと思いがち。だが全体の品質は RAGの検索品質・Vector Database・プロンプト設計・Tool設計・MCP・権限管理・ログ管理・セキュリティ に左右される。LLMはシステムの一部という「全体最適」の視点が重要。

メリット

  • 業務自動化
  • 最新情報・社内情報の活用
  • 生産性向上・品質向上

デメリット・リスク

  • 構成が複雑になる
  • 開発コスト・保守対象が増える
  • セキュリティ設計が不可欠
ここだけ覚える
  • AIシステムはLLMだけではない
  • RAG・MCP・Function Callingなどを組み合わせて構築する
  • 設計では「全体最適」が重要

10-4MCPアーキテクチャ

一言でいうとAIと外部システムを共通ルールで接続する構成。AIエージェントは多くのツールを使うため、その接続方法を標準化するのがMCP。
LLM
MCP ClientAI側の接続機能
MCP Serverツール・データを公開
Toolメール・検索・ファイル取得
API → システム
図 10-7　MCPの全体構成（Client・Server・Toolで構成）

MCP Client

AI側の接続機能。利用可能なツールを取得し、必要に応じて呼び出す

MCP Server

ツールやデータをAIへ公開。GitHub / Slack / Database / Google Drive / 社内システムなど

Tool

AIが利用する機能。メール送信・ファイル取得・検索・カレンダーなど

APIとの違い

APIは「システム同士」をつなぐ通信手段。MCPは「AIとツール」をつなぐ、AI向けの共通インターフェース。

図 10-8　MCP経由でGitHubのIssueを要約しSlackへ通知

メリット

  • ツール追加が容易
  • ベンダーに依存しにくい
  • 再利用しやすい
  • 保守性が高い

デメリット

  • MCP Serverの整備が必要
  • 権限管理が重要
  • 認証・認可の設計が必要
  • ツールが増えるほど運用が複雑
ここだけ覚える
  • MCPはAIとツールを接続する標準規格
  • MCP Client・MCP Server・Toolで構成される
  • システム全体の拡張性・保守性を高める重要技術

10-5マルチエージェントアーキテクチャ

一言でいうと複数のAIエージェントが専門分野ごとに役割を持ち、協力して1つの業務を完了させる構成。会社で営業・技術・法務・経理が分担するのと同じ。

「営業提案書を作成して」という依頼一つでも、顧客情報取得・社内資料検索・市場調査・競合分析・提案作成・レビューと複数の専門知識が要る。一つのAIが全部やるより役割を分けた方が品質も保守性も向上する。

  • User
    • Supervisor Agent ── 全体管理
      • Sales Agent ── 顧客分析・CRM検索
      • Research Agent ── Web検索・市場調査
      • Legal Agent ── 契約書確認・規約検索
      • Developer Agent ── コード生成・テスト
      • QA Agent ── レビュー・品質分析
      • Report Agent ── 結果を統合 → User
図 10-9　Supervisorが専門Agentを束ね、結果を統合する
役割担当
Supervisor AgentGoal管理・タスク分割・Agent選択・結果統合・品質管理（人間でいうPM）
Specialist Agent専門分野だけを担当（営業・研究・法務・開発・品質など）

メリット

  • 専門性が高い（1つのAIに全部覚えさせ不要）
  • 専門Agent担当で品質向上
  • 複数Agentで並列処理
  • Agent単位で保守・拡張しやすい

デメリット

  • システムが複雑になる
  • Agent間通信が必要
  • コストが高くなる
  • デバッグ・設計が難しい
ここだけ覚える
  • マルチエージェントは役割分担するAIシステム
  • Supervisorが全体を管理する
  • 複雑な業務ほど効果が高い

10-6AI導入の考え方

一言でいうとAI導入とは AIで企業の課題を解決し、生産性や品質を向上させること。AIを使うことではなく成果を出すことが目的。AIは目的ではなく手段。
✕ 誤解ChatGPTを導入しよう → AI導入完了
○ 正しくは本当に重要なのは業務改善。困っている仕事 → AIで解決、の順で考える

必ずAIからではなく業務から考える。重要なのはこの順番。

Step1 現状分析時間がかかる・人手不足・ミスが多い
Step2 課題整理本当の問題を見つける
Step3 AI適用生成AI・エージェント・OCR・RAGから選ぶ
Step4 PoCいきなり本番せず小さく試す
Step5 効果測定本当に効果があったか確認
Step6 本番導入成功したら全社展開
Step7 継続改善導入して終わりではない
図 10-11　AI導入の7ステップ（業務 → 課題 → AI の順）
120分
導入前の議事録作成時間
20分
AI導入後
効果測定の例 ── 削減効果を数字で確認する

失敗する例

AIありきで考える

「ChatGPTを使いたい→何に使おう」は逆。困っている仕事から考える

業務を理解していない

担当者が現場を理解しないと、使われないAIになる

Human in the Loopがない

AIだけに任せると誤判断。重要業務では人間確認が必須

ROIを考えていない

導入費と削減効果を比較しないと費用対効果が見えない

成功のポイント

小さく始める／効果を測る／現場を巻き込む／セキュリティを考える／Human in the Loopを設計する／継続改善する。

★第10章まとめ

この章の要点
  • LLM・RAG・Vector DB・MCPなどは独立した技術ではなく、1つのAIシステムの中で連携する
  • RAG・MCP・AIエージェントは企業AIの中核技術
  • マルチエージェントは複雑な業務ほど効果を発揮する
  • AI導入の目的は「業務改善」であり、「AIを導入すること」ではない
  • 業務理解・PoC・Human in the Loop・継続改善が成否を分ける

理解度チェック
1AIシステムについて正しいのは？
  • A. ChatGPTがあれば完成する
  • B. LLM・RAG・ツール・外部システムを組み合わせて作る
  • C. LLMだけで品質が決まる
  • D. セキュリティ設計は不要
正解：B　LLMはあくまで一部。複数技術の「全体最適」が重要。
2RAGでVector Databaseが担う役割は？
  • A. 文章を生成する
  • B. APIを呼び出す
  • C. 意味の近い文書を検索する
  • D. ツールを公開する
正解：C　Embeddingした文書を保存し、意味検索で関連文書を見つける。
3AIエージェントのPlannerとReflectionの担当は？
  • A. Plannerが振り返り、Reflectionが計画
  • B. Plannerが計画、Reflectionが振り返り・修正
  • C. どちらも文章生成
  • D. どちらもツール接続
正解：B　Plannerが計画を立て、Reflectionが結果を振り返り次へ活かす。
4MCPが必要な理由は？
  • A. LLMを高速化するため
  • B. AIと多数のツールの接続方法を標準化するため
  • C. 文書を保存するため
  • D. 画像を生成するため
正解：B　共通規格で接続を標準化し、拡張性・保守性を高める。
5マルチエージェントのメリットでないのは？
  • A. 専門性が高い
  • B. 並列処理できる
  • C. 保守しやすい
  • D. システムが単純になる
正解：D　むしろシステムは複雑になり、Agent間通信やデバッグの難しさが増す。
6AI導入で最初に行うべきことは？
  • A. 高性能なLLMを選ぶ
  • B. 全社へ一気に展開する
  • C. 業務理解・課題整理
  • D. ChatGPTの契約
正解：C　AIからではなく業務から考え、課題を整理してからAIを適用する。
7Human in the Loopが重要な理由は？
  • A. コストが下がるから
  • B. AIだけに任せると誤判断が起きるため、重要業務で人間確認が必要
  • C. 処理が速くなるから
  • D. 文書整備が不要になるから
正解：B　誤判断を防ぐため、重要な業務には人間のレビュー・承認を組み込む。
