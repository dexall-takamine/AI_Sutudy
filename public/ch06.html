AIエージェントとは何か

この章のゴール

6-1AIエージェントとは

一言でいうとAIエージェントとは、目標を達成するために自ら考え、情報を集め、ツールを使って仕事を進めるAIシステム。生成AIが「回答するAI」なら、エージェントは「仕事をするAI」。

たとえば「営業資料を作って」と頼むと、人間は市場調査・顧客情報確認・資料作成・メール送信まで行う。生成AIは資料を書くことはできても、PowerPointを保存したりメールを送ったりはできない。その一連の仕事を自律的に進めるのがAIエージェントである。OpenAI・Anthropic・Google・Microsoftなど主要各社が「次のコンピューティングの中心になる」と位置づけている。

AIエージェントは「社員」に近い

新入社員は知識だけでは仕事にならず、PC・メール・社内システム・ファイルサーバーを使って仕事をする。エージェントも同じで、LLMを頭脳とし、さまざまなツールを使いながら仕事を進める。

6-2生成AIとの違い

一言でいうと生成AIは「作るAI」、AIエージェントは「仕事をするAI」。エージェントは生成AIを頭脳として利用しながら、計画・検索・実行までを担う。

生成AI（作る）

  • 役割は「生成」
  • 質問 → 回答で完結
  • 文章・画像・音声を作る
  • 保存・送信・登録はできない

AIエージェント（仕事をする）

  • 役割は「業務実行」
  • 計画 → 検索 → ツール → 実行 → 確認
  • 顧客情報取得・承認依頼・送信まで
  • LLMを頭脳として利用する

6-3AIエージェントの構成要素

AIエージェントは1つの技術ではなく、複数の仕組みを組み合わせて動く。代表的な構成要素は次の4つ。頭脳（計画・記憶）と手足（ツール）、そして見直し（自己評価）からなる。

Planner（計画）

目標をタスクへ分解し、何を・どの順番で行うかを決める。

Memory（記憶）

会話履歴や途中経過、過去の情報を保持し、続きから作業できる。

Tool Calling（ツール利用）

検索・メール・カレンダーなど必要なツールを選び、実際に使う。

Reflection（自己評価）

結果を確認し、期待通りでなければ計画を直して再実行する。

頭脳　Goal → Planning → Reasoning → Memory
手足　RAG → Function Calling → MCP → Tool → Action
見直し　Observation → Reflection → Goal達成

Plan計画する
Action実行する
Reflect振り返る
問題があれば Plan へ戻る
図 6-3b　Plan → Action → Reflect のループを目標達成まで繰り返す

6-4Planner（計画）

一言でいうとPlannerとは、目標達成のために「何を」「どの順番で」行うかを決める仕組み。エージェントがチャットボットと大きく異なる点は、いきなり実行せずまず計画を立てること。

旅行なら「ホテル予約 → 新幹線予約 → 荷物準備 → 出発」と順番を考えるのと同じ。Plannerは目標の理解・タスク分解・優先順位・必要なツール・実行順序を考える。計画がないと思いついた順に動いてしまい効率が悪い。

Goal
顧客分析
競合・市場調査
提案書作成
レビュー
図 6-4　「営業資料作成」を最適な順番に段取りする

メリット

  • 無駄な作業を減らせる
  • 複雑な仕事に対応できる
  • ツール利用を最適化できる

デメリット

  • 計画が長いほど時間がかかる
  • 間違った計画だと全体が失敗する
  • 複雑すぎる計画は修正が難しい

6-5Memory（記憶）

一言でいうとMemoryとは、AIが過去の情報や途中経過を覚えておく仕組み。記憶がないと毎回「どの資料ですか？」と聞き直すことになり、仕事が続かない。

Short-term Memory

短期記憶。いまの会話や作業内容を覚える。

Long-term Memory

長期記憶。担当顧客・よく使う資料・好みなどを保存する。

Working Memory

作業中だけ使う記憶。途中計算・検索結果・タスク一覧など。

MemoryとRAGの違い（混同しやすい）

Memoryは過去を覚える仕組み、RAGは必要な情報を検索する仕組み。役割が違う。

観点MemoryRAG
役割過去を覚える必要な情報を検索する
対象ユーザー情報・会話履歴社内文書・FAQ・PDF
利用長期利用必要な時だけ取得
注意点

記憶が増えるほど管理が必要になり、古い情報を覚え続けることもある。個人情報の管理がとくに重要。

6-7Reflection（自己評価）

一言でいうとReflectionとは、AIが自分の結果を確認し、必要なら改善する仕組み。人がレポートを書いたあと誤字脱字を見直すのと同じ。

メリット

  • 品質向上・ミス削減
  • ハルシネーション低減
  • 自己改善できる

デメリット

  • 処理時間が増える
  • コストが増える
  • 必ず正しく直せるとは限らない
ReflectionとHuman Review

ReflectionはAI自身の確認、Human Reviewは人間による確認。企業では両方を組み合わせて使う。Reflectionは Observation とセットで利用される。

6-8Workflow Agent（定型業務型）

一言でいうとWorkflow Agentとは、あらかじめ決められた手順（ワークフロー）に沿って仕事を進めるエージェント。毎日同じ流れの仕事は、AIが毎回自由に考えるより手順どおりに動く方が効率的。

新入社員でもマニュアルがあれば仕事ができるのと同じ。問い合わせメールの分類、請求書処理、議事録保存、Slack通知などはほぼ同じ流れで処理できる。

PDF受信
OCR
金額抽出
会計登録
Slack通知
図 6-8　請求書処理ワークフロー（手順が固定されている）

メリット

  • 品質が安定する（ばらつきが少ない）
  • 運用しやすく障害の原因を特定しやすい
  • Tool・権限を限定でき安全
  • 不要な推論を減らしコストを抑えやすい

デメリット

  • 想定外の仕事が苦手
  • 柔軟な判断が難しい
  • フロー変更時に設計変更が必要

向いている仕事：OCR・経費精算・問い合わせ対応・メール振り分け・議事録作成・データ入力・定型レポート作成。

6-9Autonomous Agent（自律型）

一言でいうとAutonomous Agentとは、自ら考え計画を立て、必要に応じて行動を変えながら目標達成を目指すエージェント。「新しい市場を調査して」のように手順が決まっていない仕事に向く。

旅行代理店に「北海道旅行を計画して」と言うと、天気・飛行機・ホテル・予算を考えながら計画する。決まった正解はない。Autonomous Agentも同じで、途中で新しい情報が見つかれば計画を変更する。

自律型のリスク

考える回数が増えコスト・処理時間が増える／状況で行動が変わり予測しにくい／自由度が高いほど権限管理と監査（ガバナンス）が重要になる。

実際の企業では両方を組み合わせる

定型部分はWorkflow、判断が必要な部分だけAutonomousに任せる。例：問い合わせ受付（Workflow）→ 複雑な分析（Autonomous）→ メール送信（Workflow）。こうしてコストと品質のバランスを取る。

1AIエージェントと生成AIの最も大きな違いは？
  • A. 学習データの量
  • B. 回答 だけでなく計画・ツール利用・実行まで行うか
  • C. 日本語対応の有無
  • D. 画像を作れるか
正解：B　生成AIは「作る」で止まるが、エージェントは計画・実行まで進めて仕事を完結させる。
2Plannerの役割は？
  • A. 過去の会話を記憶する
  • B. 目標をタスクに分解し順番を決める
  • C. 外部ツールに接続する
  • D. 結果の誤字を直す
正解：B　Plannerは「何を・どの順番で」行うかを決め、目標をタスクへ分解する。
3Memoryの種類の組み合わせとして正しいのは？
  • A. 入力・出力・推論
  • B. Short-term・Long-term・Working
  • C. RAG・MCP・Function Calling
  • D. Plan・Action・Reflect
正解：B　短期・長期・作業の3種類。RAGは情報検索で役割が異なる。
4Tool Callingが必要な理由は？
  • A. LLMだけでは文章しか作れず、送信・検索などができないから
  • B. 学習を速くするため
  • C. 記憶を増やすため
  • D. 計画を不要にするため
正解：A　メール送信・カレンダー登録・検索などの実行はツールを通じて行う。
5Reflectionは何のための仕組み？
  • A. 外部システムへの接続
  • B. AI自身が結果を確認し必要なら改善する
  • C. ユーザー情報の保存
  • D. タスクの分解
正解：B　自己レビューで品質を上げる。人間によるHuman Reviewとは別物。
6次のうち Workflow Agent に向く仕事は？
  • A. 新規事業の企画
  • B. 経費精算・FAQ回答などの定型業務
  • C. 市場調査
  • D. 営業戦略の立案
正解：B　手順が固定でき再現性の高い定型業務はWorkflow向き。判断の多い仕事はAutonomous向き。
