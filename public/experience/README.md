# AIの内部処理 3D体験 ── 設計ドキュメント

「このあと雨は降りますか？」という質問を受け取ってから、AI が回答を返すまでの**内部処理**を Three.js で 3D 可視化する教材。初心者・学生・社会人が「AIって裏側でこんなことをしているんだ！」と直感的に理解することを目的とする。

すべてローカル同梱（`three.js` / `gsap` を `assets/` に同梱）で、**`index.html` をブラウザで開くだけ**で動作（サーバ不要・オフライン可）。

---

## 1. 全体アーキテクチャ

```
┌──────────────────────────────────────────────┐
│ index.html（体験ページ）                        │
│  ├─ #stage  … WebGLキャンバス（Three.js描画）   │
│  └─ #ui     … HUDオーバーレイ（DOM/CSS）        │
├──────────────────────────────────────────────┤
│ 同梱ライブラリ:  three.min.js / gsap.min.js     │
├──────────────────────────────────────────────┤
│ アプリ層（グローバル名前空間 AIX に集約）        │
│  config.js  … データ（シーン定義・トークン・解説）│
│  main.js    … Three基盤・カメラ・操作・描画ループ │
│  scenes.js  … 10シーンの3D生成 / 表示 / アニメ   │
│               + AIX.Timeline（GSAP自動再生）     │
│  ui.js      … HUD生成・更新・コントロール配線     │
└──────────────────────────────────────────────┘
```

データフロー：`config`（何を見せるか）→ `scenes`（3Dで描く）/ `ui`（説明を出す）を、`main` の描画ループと `Timeline`（再生制御）が駆動する。状態は `AIX.state`（現在シーン・時刻・再生中・速度）に集約。

## 2. シーン構成図（10シーン）

```
1 入力 ── 質問が光の粒となりAIへ
2 Tokenization ── 文を立方体トークンに分割
3 Embedding ── 数字ベクトル化。銀河状の意味空間（近い意味は近くに）
4 Transformer ── 積層レイヤーを通過、層ごとに色が変化
5 Attention ── 重要な語どうしをレーザー接続（重み=太さ）★最重要
6 知識検索 ── 知識ネットワークの関連ノードが発光（RAGは外部DB）
7 推論 ── 天気/時刻/場所/意図 を統合（コア＋リング）
8 Token Prediction ── 「今」→「今日は」→… 1トークンずつ生成
9 返却 ── 回答が光となりチャットUIへ
10 ログ ── ✔チェックリストで全工程を振り返り
```

自動再生は `AIX.Timeline`（GSAP）が `config.scenes[].dur` 秒ごとに `AIX.setScene(i)` を呼ぶ。

## 4. クラス／モジュール設計

| 名前空間 | 役割 | 主なAPI |
|---|---|---|
| `AIX.CONFIG` | データ定義 | `scenes[]`, `tokens[]`, `glossary{}`, `color{}` |
| `AIX.state` | 実行状態 | `current, clock, sceneClock, playing, speed` |
| `AIX.three` | 描画資源 | `renderer, scene, camera, root, stars` |
| `AIX.Scenes` | 3D生成と更新 | `build()`, `show(idx)`, `update(dt)` |
| `AIX.Timeline` | 自動再生 | `build(), play(), pause(), toggle(), speed(v), goto(i), next(), prev()` |
| `AIX.UI` | HUD | `init(), onScene(idx), onProgress(p), tick(), showGlossary(key)` |
| `AIX.setScene(idx)` | シーン切替の司令塔 | 表示制御＋UI更新＋視点tween |
| `AIX.boot()` | 起動 | 上記を初期化し描画ループ開始 |

設計方針：**データ（config）と表現（scenes/ui）を分離**。シーン固有の動きは「タイムライン（カメラ・進捗・切替）」と「描画ループ内のアンビメ（トークン回転・タイピング等）」に役割分担。後者は時刻ベースなのでシーンジャンプしても破綻しない。

## 6. Three.js コード（要点）
- `main.js`：`WebGLRenderer` / `PerspectiveCamera` / 照明（Ambient+Directional+2 PointLight）/ 背景の星（`Points`）/ ルートグループ / `Raycaster`（クリック判定）/ 描画ループ。
- `scenes.js`：各シーンを `THREE.Group` 単位で生成。`BoxGeometry`（トークン/レイヤー）、`Points`（Embedding銀河）、`TubeGeometry`/`QuadraticBezierCurve3`（Attention曲線）、`IcosahedronGeometry`+`TorusGeometry`（推論コア/リング）、`CanvasTexture`+`Sprite`（テキストパネル）。

## 7. アニメーションコード（要点）
- **GSAP**：`AIX.Timeline` がマスター `gsap.timeline({repeat:-1})`。各シーンに `tl.call(setScene)` + ダミー尺。`timeScale` で速度、`seek` でジャンプ。視点切替も `gsap.to(AIX.view,…)`。
- **描画ループ側の常時アニメ**（`AIX.Scenes.update`）：入力粒子の落下、トークン回転、銀河回転、Transformerマーカー走査＋層発光、Attention重みの脈動、知識ノード点滅、推論コア/リング回転、予測パネルの逐次タイピング、返却ビーム移動。

## 8. UI コード（要点）
`ui.js` が DOM を動的生成（ステータス／フロー／解説／コントロール／用語モーダル）。`onScene` で各表示を更新、`onProgress` で進捗バー、ボタンは `AIX.Timeline` に接続。

## 9. CSS（要点）
`app.css`：`backdrop-filter` のガラスHUD、ネオングラデーション（cyan→purple）、`tabular-nums` の数値、`@media` でモバイル簡略化（左フロー非表示等）。

## 10. 教材としての解説文（そのまま掲示可）

> **AIは「考えて」答えているのではなく、決まった処理を高速にこなしているだけ。**
> あなたが質問を入力すると、文章は①小さな単位（トークン）に分けられ、②意味を表す数字（ベクトル）に変換されます。③巨大なネットワーク（Transformer）を通り、④どの言葉が重要かを見る「Attention」で文脈をつかみます。⑤関連する知識を呼び出し、⑥情報を統合して、⑦続きの単語を1つずつ予測しながら回答を作り、⑧あなたに返します。
> この10ステップが、たった一つの質問の裏側で一瞬のうちに動いています。仕組みを知ると、AIの“得意・苦手”や“なぜ間違えるのか”も見えてきます。

## 11. 改善案
- OrbitControls 同梱で慣性付きカメラ操作（現在は自前のドラッグ/ズーム）。
- ポストプロセス（UnrealBloom）で発光をより映画的に。
- 任意の質問を入力 → 実際にトークン化して可視化（簡易トークナイザ同梱）。
- 各シーンにナレーション音声／字幕、BGM。
- `prefers-reduced-motion` で自動再生を抑制、アクセシビリティ強化。
- パネルテキストは `Sprite` でなく CSS2DRenderer にして高解像度・選択可能に。

## 12. 今後追加できる機能（発展）
- **RAG**：Scene6 に「外部DB / ベクトル検索」レーンを追加し、社外文書ノードから関連チャンクを取り込む演出。
- **Browser Agent**：回答前に「ブラウザを開いて天気を調べる」サブシーン（実時間の天気取得を模式化）。
- **Computer Use**：画面操作（クリック・入力）を行うエージェントの可視化。
- **MCP**：外部ツール群（カレンダー/メール/DB）と AI を結ぶ“接続規格”をハブ＆スポーク図で表現。
- **マルチエージェント**：複数コアが分担・議論して1つの回答に集約する様子。
