08実践

AIはどのように仕事をこなすのか

この章のゴール
代表的な10業務を題材に、AIが内部でどう処理し、エージェントならどこまで自動化できるかを理解する。LLM・RAG・Browser Agent・Function Calling・MCP が実務でどう組み合わさるかを、自分の言葉で説明できるようになる。
この章の項目
  1. メール分類
  2. スケジュール調整
  3. 会議の議事録作成
  4. Web検索と情報収集
  5. 営業資料作成
  6. 問い合わせ対応
  7. OCRによる請求書処理
  8. ソフトウェア開発
  9. テスト設計・品質保証
  10. AIコンサルティング
この章の見方各業務を 「人間が行う場合」「AI内部の処理」「エージェントの自動化範囲」 の3視点で比較する。技術を個別に使うのではなく、組み合わせて一連の仕事をこなす点に注目する。

8-10AIコンサルティング

一言でいうと企業の課題を整理し、生成AIやAIエージェントを活用して業務改善を支援する仕事。AI導入が目的ではなく、課題解決が目的。
✕ 誤解AIコンサルティング＝「ChatGPTを導入すること」
○ 正しくは課題 → 原因分析 → 業務改善 → AI適用 → 効果測定 → 継続改善。AIは目的ではなく手段

図 8-10　エージェントの自動化範囲（使用技術：LLM／Browser Agent／RAG／Vector Database／MCP／Function Calling／Multi-Agent／BIツール／CRM／ERP）

AIコンサルタントは現状調査→業務分析→課題整理→AI適用検討→PoC（試験導入）→評価→本番導入と進める。AIはこのすべてを置き換えるのではなく、資料分析・市場調査・業務整理・提案資料作成を大きく支援する。代表的な適用例は次のとおり。

品質保証（QA）

社内問い合わせ

散在する社内文書をEmbedding→Vector DB→RAGでAIチャット化

SI・コンサル企業

課題整理→現状分析→PoC→効果測定→本番→運用改善

メリット

  • 調査時間を大幅短縮・提案品質向上
  • PoCを短期間で実施
  • 社内ナレッジを活用・提案書作成を効率化

リスク

  • 現場業務を理解しないと適切な提案ができない
  • ハルシネーションによる誤提案
  • ROI評価・セキュリティ・ガバナンスが必要
ここだけ覚える
  • AIコンサルティングは「AI導入」ではなく「課題解決」が目的
  • AIは分析・資料作成・調査を支援できる
  • 最終的な提案や意思決定は人間が担当する

この章の要点
  • AIは業務の一部だけでなく、一連の流れを支援できる
  • エージェントは複数の技術を組み合わせて仕事を進める
  • AIが得意なのは「情報処理」、人間が得意なのは「判断・責任・コミュニケーション」
  • 多くの業務は Goal→Planner→ツール→Action→Reflection→Human Review の共通フローで動く
  • AIが人間を置き換えるのではなく、AIと人間の協力が重要

理解度チェック
1メール分類でAIが内部で行う処理の流れは？
  • A. OCR → 承認 → 保存
  • B. Token化 → Embedding → LLM分類 → ラベル付与
  • C. 音声認識 → 要約 → 投稿
正解：B　メールを数値化（Embedding）し、LLMが意味で分類してラベルを付ける。
2スケジュール調整でFunction Callingが担う役割は？
例　LLMがCalendar API（Google Calendar等）を呼び出して空き時間検索・予定登録・招待メール送信といった外部操作を実行する。
3議事録作成で音声認識とLLMが担当するのは？
例　音声認識（ASR）が音声を文字に起こし、LLMがそれを要約して議事録化し、決定事項やToDoを抽出する。
4営業資料作成でBrowser AgentとRAGはどう使い分ける？
例　RAGは社内（CRM・過去提案・顧客情報）の参照、Browser Agentは社外Webの市場調査・競合分析に使う。
5OCRだけでは請求書処理が完了しない理由は？
例　OCRは文字抽出までで、項目理解（LLM）やERP登録、金額確認・承認（人間）が必要。OCR誤認識やフォーマット差異もあるため。
6ソフトウェア開発でAIが得意なことを3つ挙げると？
例　コード生成・テストコード生成・ドキュメント生成（レビュー支援も可）。設計や品質判断は人間が担当。
7品質保証でAIと人間が担当するのは？
例　AIはテストケース生成・自動テスト実行・品質分析、人間は品質判断・最終承認・非機能評価を担当する。
8AIコンサルティングで最も重要なのは？
  • A. ChatGPTを導入すること
  • B. 企業の課題を解決すること
  • C. 最新モデルを使うこと
正解：B　AIは目的ではなく手段。課題整理から効果測定・継続改善までが本質。
9エージェントの共通フローをGoalからHuman Reviewまで説明すると？
例　Goal → Planner（計画）→ RAG／Browser Agentで情報収集 → Tool・Function Callingで実行 → Action → Reflection（自己検証）→ Human Review（人間の確認）→ 完了。
10（応用）自分の業務でAIと人間の担当を整理すると？
解答例なし　業務を1つ選び、情報処理（AI）と判断・責任（人間）に分けて整理できれば理解できている。
